# Archive 88

Online shop for **Archive 88**: curated pieces, made in limited runs. Est. 1988.
100 styles (sample data) with size × colour variants, a listing page with a sticky filter sidebar, product pages
with a variant matrix and a mobile sticky Add to bag, a slide-out bag, search, gift cards by email or post, and
the info pages a shop needs.

Live: https://nickwalsh-rgb.github.io/Animated-website/

The identity (logo, colour, type) was redrawn in 2026 from the original Figma logo; it lives on the **Rebrand 2026**
page of the Figma file and in [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md).

Plain HTML, CSS and JS with no frameworks or animation libraries. Pages are generated by `build.py` (Python standard
library; Pillow optional, for photo resizing). Fonts are self-hosted in `assets/fonts/`.

## Launching with your own clothes

1. **Styles**: replace the sample entries in `data/catalog.json` with yours (name, style number, price, colours, sizes, stock). The build tells you plainly if a field is missing.
2. **Photos**: drop them into `assets/products/<handle>/` named `<colour>-1.jpg` (front), `-2` (alternate angle), `-3`, `-4`. They are cropped to 4:5 and resized for you. Styles without photos show placeholder art until then.
3. **Words and pictures on the homepage**: the `home` block in `data/store.json`.
4. **Business details, delivery wording, social links, Shopify domain**: `data/store.json`, then work through *Before launch* below.

Commit to `main` and the site rebuilds and publishes itself.

## Editing on GitHub (no setup needed)

Edit `data/catalog.json`, `data/store.json`, the pages in `src/pages/`, or upload photos straight on github.com.
When the change lands on `main`, the **Build site** workflow (`.github/workflows/build.yml`) rebuilds the pages,
makes web-sized photos, commits the result and publishes it. You can also run it any time from the **Actions** tab.

## Everyday editing

| To change | Edit | Then |
| --- | --- | --- |
| Styles, prices, colours, sizes, stock | `data/catalog.json` (`stock[colour][size]` is the variant matrix) | `python3 build.py` |
| Product photos | `assets/products/<handle>/<colour>-<n>.jpg` (see that folder's README; cropped to 4:5 by the build) | `python3 build.py` |
| Homepage headline, copy, pictures and links | the `home` block in `data/store.json` | `python3 build.py` |
| Announcement bar, categories, free-delivery threshold, page size, gift cards, social links, business details, shipping wording, Shopify domain | `data/store.json` | `python3 build.py` |
| About, Size guide, Delivery & returns, Contact, Privacy, Terms | `src/pages/*.html` | `python3 build.py` |
| Markup of any component | `components.py`, `build.py` | `python3 build.py` |
| Tokens, styles, behaviour | `assets/css/tokens.css`, `assets/css/store.css`, `assets/js/*.js` | refresh |
| The logo itself | `tools/make_brand.py` (writes `assets/brand/*.svg`, the favicon and `src/brand-defs.html`) | `python3 tools/make_brand.py`, then `python3 build.py` |
| Share image and app icons | `tools/make_icons.js` | `node tools/make_icons.js` |

```bash
python3 build.py              # rebuild everything
python3 -m http.server 8080   # preview at http://localhost:8080
python3 tools/seed_catalog.py # regenerate the SAMPLE catalogue (overwrites data/catalog.json)
python3 tools/make_sprite.py  # rebuild the icon + garment sprite (assets/sprite.svg)
python3 tools/make_brand.py   # redraw the logo files (needs: pip install fonttools brotli)
```

`index.html`, `shop/`, `products/`, `gift-cards/`, the info page folders (`about/`, `contact/`...), `404.html`,
`search.json`, `sitemap.xml` and `robots.txt` are **generated**. Don't edit them by hand.

The build stops with a clear message if a style is missing a field, has a duplicate handle or style number, an
unknown category or a missing stock cell.

## Pages

| Page | What's on it |
| --- | --- |
| Home `/` | Film hero with the turning seal, name band, New in rail, statement, archive index, two stories, Most wanted, banner |
| Shop `/shop/`, `/shop/<category>/` | Sticky filter sidebar (drawer on phones), sort, Load more; filters kept in the address (`?size=M&colour=green`) |
| Product `/products/<handle>/` | Gallery, colour and size selectors, stock messages, availability matrix, sticky Add to bag on phones, You may also like |
| Gift cards `/gift-cards/` | Amount, then Email or Post, each with its own form and a live card preview |
| Info | About, Size guide, Delivery & returns, Contact, Privacy, Terms of sale |
| 404 | Page not found, with search. Also forwards old `/storefront/...` links to their new address |

Shared on every page: announcement bar, header that turns see-through over imagery, desktop mega-menu, search,
bag drawer, service bar, newsletter sign-up, footer with a light / dark theme switch.

Brand, tokens, components and UX rules: [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md).

## Before launch

All product data is **sample data**.

- [ ] Real styles, prices and stock in `data/catalog.json`; photos in `assets/products/<handle>/`
- [ ] Real campaign photography: the homepage uses stills from the forest film in every picture slot. Add your own to `assets/img/` and point the `home` block in `data/store.json` at them
- [ ] Check the brand claims are true for you: "limited runs", "Est. 1988" and "repairs for life" come from the logo and the draft copy
- [ ] Business details in `data/store.json`: currently **placeholders** (fictional company, Ofcom drama phone number, `.example` email)
- [ ] Real Instagram/Facebook URLs and shipping wording in `data/store.json`
- [ ] Size guide measurements in `src/pages/size-guide.html` (currently sample numbers)
- [ ] The About story in `src/pages/about.html` is a **draft**: edit it to your real story
- [ ] The providers list in `src/pages/privacy.html`, gift card validity in `src/pages/terms.html`
- [ ] Privacy and Terms reviewed, then set `"legal_reviewed": true` in `data/store.json`
- [ ] Shopify connected: `shopify_domain` in `data/store.json` and `shopify_variant_ids` per style (see the design doc)
- [ ] Newsletter connected to an email provider (`window.A88S.subscribe(email)` in `assets/js/store.js`)
- [ ] Site URL in `data/store.json` if moving to your own domain

```
components.py            one function per UI component (card, rail, drawer, selectors...)

src/pages/               About, Size guide, Delivery & returns, Contact, Privacy, Terms (content)

assets/brand/            logo files: lockup, wordmark, stacked, seal, roundel (emblem), monogram
assets/css/              tokens.css (design tokens), store.css (components)
assets/js/               store.js (shared), motion.js (reveals, page transitions, theme switch), plp.js, pdp.js, home.js, gift.js
assets/sprite.svg        icons + placeholder garment art (tools/make_sprite.py)
assets/products/         product photos (one folder per style)
assets/fonts, img, video self-hosted fonts, images, the forest film
tools/                   sample catalogue, sprite, logo and icon generators
docs/DESIGN-SYSTEM.md    brand, tokens, components, UX rules
.github/workflows/       automatic rebuild on GitHub
```
