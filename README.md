# Archive 88

Scroll-animated shop front for **Archive 88**, built from the Figma brand file ("05 Quiet Caps" wordmark,
A88 monogram, woven label). Ready to fill with real pieces, photos and drop dates, and to move to Shopify.

Plain HTML, CSS and JS. GSAP, ScrollTrigger and Lenis are vendored in `assets/vendor/`, fonts are self-hosted
in `assets/fonts/`. Pages are generated by a small Python script (standard library only).

## Everyday editing

| To change | Edit | Then |
| --- | --- | --- |
| Pieces (name, price, size, measurements, condition, sold) | `data/products.json` | `python3 build.py` |
| Product photos | add files to `assets/products/<handle>/` (see that folder's README) | `python3 build.py` |
| Next drop date, social links, shipping text, returns FAQ, categories | `data/site.json` | `python3 build.py` |
| Page layout and copy | `src/partials/*.html` | `python3 build.py` |
| Styles / motion | `assets/css/style.css`, `assets/js/*.js` | refresh |

`index.html`, `products/`, `shopify/products.csv`, `sitemap.xml` and `robots.txt` are **generated**. Don't edit them by hand.

```bash
python3 build.py              # rebuild everything
python3 -m http.server 8080   # preview at http://localhost:8080
```

The build stops with a clear message if a product is missing a field, has a duplicate number or an unknown
category, and lists any pieces that are still waiting for photos.

## Pages

**Homepage** `index.html`
- Hero: wordmark, one line, the next drop date and "Shop the archive". The 3-second loader plays on the first visit of a session only.
- Film: a small window opens into the graded forest film.
- Story, then **the archive**: a pinned sideways row of hang tags with a thin progress line. Each tag shows the first photo (or the monogram until photos exist), links to its product page, and has Add to bag. Sold pieces stay, greyed out with a Sold stamp.
- Label, marquee, **Returns** and **Join the list** (sharing one colour band; the email field has a visible label).

**Product pages** `products/<handle>/`
- Gallery of every photo in the piece's folder. With no photos yet it shows labelled slots from the shot list (Front, Back, Label, Detail, Flaws). Phones swipe sideways with a pager line.
- Number, name, price, size / era / condition, description, Add to bag (or Sold + Join the list), final-sale note when set.
- Details: measurements table (cm), condition and flaws, material, shipping, returns.
- More from the archive: three related pieces.
- Own share preview (product photo when available), `product:*` Open Graph tags and Product + Breadcrumb structured data for Google.

**Shared on every page:** category menu (counts come from the data; on product pages a category goes to that piece on the homepage), bag drawer saved in the browser, raised social keys, footer.

## Motion

| Where | What |
| --- | --- |
| Loader (first visit) | Letters rise while a counter runs 00 to 88, then the panel lifts |
| Hero | Letters rise in, then drift apart at different speeds as you scroll |
| Film | Window opens to full screen; caption rises in |
| Story | Words light up as you read |
| Archive | Pinned sideways scroll; tags swing with scroll speed |
| Product page | First photo unmasks upward, details rise in; later photos unmask on scroll |
| Menu / bag / accordions | Wipe, slide and measured-height animations |
| Social keys | Lift and tilt toward the cursor; press flush on click |

`prefers-reduced-motion` turns all of it off. Revealed content fades with opacity only, so keyboard users can reach it before it scrolls into view.

## Before launch

All product data is **sample data**: names, prices, sizes, measurements, materials and conditions in `data/products.json`.

- [ ] Real pieces in `data/products.json`, photos in `assets/products/<handle>/`
- [ ] Real drop date in `data/site.json` (it is a sample: Friday 4 December 2026, 7pm). It hides itself once the date passes.
- [ ] Real Instagram/Facebook URLs in `data/site.json`
- [ ] Real shipping wording in `data/site.json`
- [ ] Returns wording checked against your policy and UK consumer law (14-day right to cancel online orders)
- [ ] Site URL in `data/site.json` if not using `nickwalsh-rgb.github.io/Animated-website`
- [ ] Shopify set up: see [docs/SHOPIFY.md](docs/SHOPIFY.md). Checkout and email sign-up are wired there.
